# การแก้หน้าบ้านและหลังบ้าน — ตรวจในเครื่อง 12 ตุลาคม 2569

## ขอบเขต

งานนี้เปลี่ยนเฉพาะไฟล์ในเครื่อง ไม่ deploy เว็บ ไม่อัปเดตฐานข้อมูลหรือ Edge Functions จริง และไม่สร้างข่าว ค่าปรับ ผลสอบ หรือเกียรติบัตรทดลองในระบบจริง

## สิ่งที่แก้

- ตรวจขนาดไฟล์ก่อนอ่าน จำกัดการส่งผ่าน Apps Script ที่ 25 MB และรักษานามสกุลเมื่อย่อชื่อไฟล์ภาษาไทย
- คำขอ Apps Script และ API จัดการหลักสูตรมี timeout 30 วินาที; อัปโหลด 90 วินาที ไม่ลองบันทึกซ้ำอัตโนมัติ เมื่อหมดเวลาระหว่างเขียนแจ้งให้ตรวจรายการก่อนส่งใหม่
- คำขอบันทึก Apps Script ที่เหมือนกันและเกิดพร้อมกันในบัญชีเดียวใช้คำขอเดียว บัญชีต่างกันไม่แชร์คำขอ
- หน้าการเงินตรวจผลทุกคำขอและอัปเดตข้อมูลเป็นชุด เก็บข้อมูลเดิมเมื่อโหลดล้มเหลว พร้อมคำเตือน เวลาอัปเดต และปุ่มรีเฟรช ป้องกันข้อมูลเก่าทับผลบันทึกใหม่และหยุด polling เมื่อแท็บซ่อน
- สถิติฝ่ายใช้แหล่งข้อมูลเดียวกับหลังบ้าน (10 ฝ่าย) ยอดข่าวใช้คำขอ HEAD แบบ exact count พร้อมสถานะผิดพลาดและลองใหม่
- ฟอร์มข่าวและสื่อที่ปรับใช้กริดหนึ่งคอลัมน์บนมือถือ ป็อปอัปแจ้งเตือนมีบทบาท dialog โฟกัสคีย์บอร์ด ปิดด้วย Escape และรองรับ reduced motion
- ผู้ดูแลใช้แบบเกียรติบัตรรวมของหลักสูตร โดยยังเชื่อมกับ civic-5 ภายในระบบ สถานะ PDF เป็น pending/processing/ready/failed
- เตรียม API และ migration ให้แอดมินลองจัดทำ PDF ของงานที่ล้มเหลวอีกครั้ง ใช้ใบและงานเดิม ปฏิเสธใบพร้อมแล้ว งานกำลังทำ และใบยกเลิก ไม่เปิดการออกใบอัตโนมัติ

## ผลตรวจที่ผ่าน

- Build สำเร็จ และ ESLint ของโมดูลหลักที่แก้
- Automated tests 7 รายการ: ขอบเขต 25 MB, ชื่อไทยยาว, base64, timeout ระหว่างอ่าน response body, ไม่มี retry อัตโนมัติ, การรวมคำขอซ้ำ, แคชลิงก์และสถานะ PDF, สิทธิ์ API แอดมิน
- ฐานข้อมูลจำลอง PGlite: retry ใช้เลขใบ/งานเดิม, ปฏิเสธผู้ไม่มีสิทธิ์และสถานะขัดแย้ง, ผ่านเพียง 4 วิชาไม่ออกใบ, ผ่านครบ 5 วิชาอย่างน้อย 8/10 ออกหนึ่งใบและไม่ซ้ำ
- เบราว์เซอร์กับ API จำลอง: การเงินเก็บ snapshot เมื่อคำขอหนึ่งล้มเหลว รีเฟรชกลับได้และหยุด polling เมื่อซ่อนแท็บ; ไฟล์เกิน 25 MB ถูกปฏิเสธก่อนอ่าน; Tab/Escape ของป็อปอัป
- ตรวจหน้าบ้าน ฟอร์ม และหน้าเรียนที่ 320, 390, 768, 1440 px รวมถึงมือถือแนวนอน ไม่พบ JavaScript exception ในเส้นทางทดสอบ
- ตรวจเส้นทางก่อนเรียน 10 ข้อ โปรไฟล์ สไลด์ก่อนคลิป การไปคลิปถัดไปและกลับมาเรียนต่อ รวมถึงหน้าดาวน์โหลดเกียรติบัตรด้วยข้อมูลจำลอง

## ข้อจำกัดและขั้นเปิดใช้

ผลข้างต้นเป็นการทดสอบในเครื่องด้วยข้อมูลจำลองและ SQL จริงบนฐานข้อมูลจำลอง ไม่ยืนยันการส่งไฟล์ Apps Script จริง โควตา Google การจัดทำ PDF ของบัญชีโรงเรียน หรือความเร็วเครือข่ายผู้ใช้จริง และไม่รับรองว่าไม่มีบั๊กทุกเส้นทาง

ยังมี lint เดิมในหน้าอื่นที่ไม่ใช่โมดูลหลักของการแก้ครั้งนี้ งานล้างโค้ดทั้งระบบแยกจากงานนี้

เมื่ออนุมัติเปิดใช้ ให้ตรวจและใช้ migration `20261011170304_certificate_pdf_retry.sql` ก่อนอัปเดต Edge Functions `learning-admin` และ `learning-v2` แล้วจึง deploy เว็บ การแก้ request/upload ครั้งนี้ไม่ต้องเปลี่ยน Apps Script โดยตัวมันเอง แต่ต้องตรวจว่า worker จัดทำ PDF ที่มีอยู่เข้ากันได้ก่อนทดสอบด้วยบัญชีจริง

ไม่มีการเปลี่ยนเกณฑ์เรียน: ผ่านอย่างน้อย 8/10 ครบทั้ง 5 วิชาเพื่อรับเกียรติบัตรรวมหนึ่งใบ
