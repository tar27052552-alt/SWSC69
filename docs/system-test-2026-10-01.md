## สิ่งที่แก้ในรอบนี้

1. เส้นทางตรวจเวอร์ชันหลังบ้านใช้ Vite BASE_URL แทน relative path ซึ่งเดิมกลายเป็น /admin/admin/index.html
2. ป้องกัน OneSignal เริ่มซ้ำจาก React StrictMode และไม่เริ่มบน dev server: ก่อนแก้พบ pageerror “SDK already initialized” และโดเมนไม่ตรง
3. เพิ่มชนิดข้อมูลผล RPC อ่านข้อสอบใน learning-admin เพื่อแก้ Deno TS7006
4. เกียรติบัตรแสดงสถานะส่งอีเมลล้มเหลวจริง แทนคำว่า “กำลังดำเนินการ” และแสดงวันออกตามเวลาไทย

ไฟล์ regression ที่เก็บไว้: tests/local-navigation-smoke.mjs รันด้วย node tests/local-navigation-smoke.mjs
ผลและ browser fixtures ระหว่างทำงานอยู่ใน .learning-source ซึ่งไม่ติดตามใน Git

## ข้อจำกัดและรายการที่ยังต้องตรวจ

- คะแนน 5/6/7/8 รอบนี้ทดสอบ UI ด้วยผลจาก API จำลองและอ่านโค้ดการคิดคะแนนของเซิร์ฟเวอร์ ยังไม่ได้สร้างผลสอบจริงในฐานข้อมูลหรือทดสอบธุรกรรมออกใบจริง
- ไม่ได้ทดสอบ Google OAuth ด้วยบัญชีมนุษย์ใหม่ การส่ง PDF/อีเมลจริง โควตา การเปลี่ยนชื่อและออกใบย้อนหลัง การเงิน SlipOK และการอัปโหลดไฟล์จริง
- ไม่ได้ตรวจความถูกต้องของเนื้อหา เฉลย และทุกหน้าของ PDF หรือเล่นวิดีโอทั้ง 60 รายการจริง
- การจำข้ามอุปกรณ์จำลอง server position หลัง reload ยังไม่ได้ใช้โทรศัพท์สองเครื่องจริง
- การเปิดหลังบ้านด้วยข้อมูลว่างไม่ครอบคลุมชุดข้อมูลจำนวนมาก ทุก role และการเขียน/แก้/ลบทุกฟอร์ม
- ESLint ยังไม่ผ่าน: baseline 107 errors และ 12 warnings ใน 25 ไฟล์ ส่วนใหญ่ no-unused-vars และ set-state-in-effect/exhaustive-deps ไม่มี no-undef หรือ parse error ในผลตรวจนี้ ยังไม่ถือว่าระบบผ่าน lint และไม่ได้ปิด rule เพื่อให้รายงานเป็นสีเขียว

ผลนี้ยืนยันเฉพาะรายการที่ทดสอบ ไม่ใช่การรับรองว่าทุกกรณีของระบบไม่มีข้อผิดพลาด
