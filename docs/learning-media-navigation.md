# การเรียนสไลด์และวิดีโอตามลำดับ

หน้าเรียนแสดงเอกสาร PDF ก่อนวิดีโอ โดยแสดงครั้งละหนึ่งสื่อ กดก่อนหน้า/ต่อไปได้ทันที สุดท้ายกด “จบหัวข้อนี้และไปต่อ” เพื่อใช้ขั้นตอนบันทึกความคืบหน้าเดิม

ตำแหน่งที่จำคือวิชา หัวข้อ และสื่อที่เปิดล่าสุด ไม่ใช่วินาทีที่เล่นวิดีโอหรือเลขหน้าภายใน PDF ระบบอ้างอิงสื่อด้วย path ของเอกสารหรือ ID วิดีโอ เพื่อรองรับการแทรกหรือเรียงสื่อใหม่

## สถานะในเครื่อง

- หน้าเว็บจำตำแหน่งในเบราว์เซอร์โดยแยกตามบัญชีผู้เรียน
- หาก catalog ไม่ส่ง `resumeEnabled: true` จะไม่เรียก API บันทึกตำแหน่งใหม่ จึงใช้กับ backend เดิมได้
- ติดตั้งตารางและ API สำหรับจำข้ามอุปกรณ์บน Supabase แล้ว หน้าในเครื่องเริ่มซิงก์ตามบัญชีได้หลังรีเฟรช

## ลำดับการติดตั้ง backend

1. ใช้ migration `20261001150123_learning_media_positions.sql` ก่อน
2. อัปเดต Edge Function `learning-v2` จากไฟล์ในโครงการ
3. ฟังก์ชันจะส่ง `resumeEnabled: true` และหน้าเว็บจะเริ่มอ่าน/บันทึกตำแหน่งตามบัญชี

`save_position` ตรวจบัญชี Google วิชาที่ปลดล็อก ข้อสอบก่อนเรียน หัวข้อก่อนหน้า และตัวระบุสื่อบนเซิร์ฟเวอร์ ผู้เรียนแก้ตำแหน่งของผู้อื่นหรือใช้ตำแหน่งเพื่อข้ามหัวข้อที่ล็อกไม่ได้ ตารางเปิด RLS และผู้เรียนมีสิทธิ์อ่านเฉพาะแถวตนเอง

ตรวจ build, Deno type check, ลำดับสื่อและการเลือกตำแหน่งล่าสุด รวมถึงเส้นทางในเบราว์เซอร์ด้วย API จำลองแล้ว หลังผู้ใช้อนุญาตได้อัปเดต Supabase และตรวจว่า API จริงส่ง `resumeEnabled: true` พร้อมตรวจ RLS/สิทธิ์ตารางแล้ว หน้าเว็บชุดนี้ยังไม่ได้เผยแพร่บน Vercel และยังไม่ได้ตรวจการเรียนต่อบนสองอุปกรณ์ด้วยบัญชี Google จริง
