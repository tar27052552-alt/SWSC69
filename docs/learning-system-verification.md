# ผลทดสอบหน้าเรียนและการแก้บั๊ก — 11 ตุลาคม 2569

## บั๊กที่แก้เพิ่ม

- คำตอบ API ที่มาช้าหลังผู้เรียนกลับหน้าเส้นทางเรียนเปิดหน้าข้อสอบขึ้นมาเอง: จำลองให้ล้มเหลวก่อนแก้ และผ่านหลังแก้ด้วยการตรวจลำดับคำขอ
- ผลส่งข้อสอบที่มาช้าอาจทับสถานะหลังเปลี่ยนหน้า: ตรวจลำดับคำขอก่อนแสดงผลและยกเลิกสถานะรอจากการนำทาง
- จบหัวข้อแล้วผู้เรียนเปลี่ยนหน้าระหว่างบันทึก: ไม่ให้ผลคำขอเก่าเปิดหัวข้อถัดไปทับหน้าใหม่
- เปิดเกียรติบัตรหลังรอ API เสี่ยงถูกบล็อกบนมือถือ: เปิดหน้ารอจากการคลิกโดยตรง แยก window.opener และใช้หน้าเดิมเป็นทางสำรองหากป็อปอัปถูกบล็อก
- เมนูส่วนหัวขณะทำข้อสอบ: ถ้ามีคำตอบที่ยังไม่ได้ส่ง จะถามก่อนออกจากหน้า

## ผ่านการทดสอบในเครื่อง

- โปรไฟล์ที่ยังไม่ครบไปหน้ากรอกข้อมูล เบอร์ไม่ถูกต้องบันทึกไม่ได้ และบันทึกโปรไฟล์แล้วไปหน้าเรียน
- ข้อสอบก่อนเรียน 10 ข้อ ต้องตอบครบก่อนส่ง; อ่าน PDF ก่อนคลิป; ดูทีละคลิป; จบหัวข้อและเรียนต่อ; รีเฟรชแล้วจำคลิปล่าสุด
- หลังเรียน 5/10 ไม่เปิดวิชาถัดไป; 6/10 และ 7/10 เปิดวิชาถัดไป; 8/10 ถึงเกณฑ์รายวิชา; สอบซ้ำได้
- SQL จำลอง: ผ่านเพียง 4 วิชาหรือวิชาที่ 5 ได้ 7/10 ยังไม่ออกใบ; ผ่านครบ 5 วิชาที่อย่างน้อย 8/10 ออกใบและงานสร้าง PDF ครั้งเดียว
- สถิติแอดมินนับบัญชี/ใบปัจจุบันไม่ซ้ำ ไม่รวมหลักสูตรเก่า และปฏิเสธสมาชิกหรือผู้ดูแลที่ถูกระงับด้วย API handler จำลอง
- สถานะโหลดทันที, การใช้แคช, ลิงก์หมดอายุ, PDF รอ 15 วินาที, API รอ 30 วินาที, โหลดล้มเหลว/ลองใหม่, กลับหน้าระหว่างโหลด, ออกจากระบบระหว่างโหลด
- หน้าจอ Chromium จำลอง 320, 390, 768, 1024 และ 1440 px รวมถึงแนวนอน 844×390 px; ไม่พบข้อผิดพลาด JavaScript ในชุดทดสอบหน้าเรียน
- ดาวน์โหลดใบในหน้าต่างใหม่และทางสำรองเมื่อถูกบล็อก ผ่านด้วย URL เอกสารจำลอง
- ESLint เฉพาะไฟล์หน้าเรียนที่แก้และ production build ผ่าน

## ตรวจบริการจริงแบบอ่านอย่างเดียว

- learning-v2 catalog ตอบ 200 และแสดงหลักสูตรเผยแพร่ 5 วิชา
- ผู้ไม่ล็อกอินเรียก me, quiz, material, download ไม่ได้ (401)
- ผู้ไม่ล็อกอินเรียก learning-admin list และ learner_overview ไม่ได้ (401)
- รายการ Storage และเอกสาร/คลิปจริง: ดู civic-learning-media-audit.md

## ข้อจำกัดที่ต้องทดสอบก่อนเปิดใช้จริง

- Google OAuth กลับมายังเว็บจริง, การเรียนด้วยบัญชีจริงสองอุปกรณ์ และการสร้าง/ดาวน์โหลด PDF เกียรติบัตรจริงทั้งเส้นทางยังไม่ได้ทดสอบในรอบนี้
- ชุด browser ใช้บริการจำลอง ไม่ได้สร้างบัญชีใหม่หรือแก้คะแนนผู้เรียนจริง และไม่ได้ออกเกียรติบัตรจริง
- วิดีโอจริง 59 รหัสอ่าน metadata ได้ แต่การเล่นแบบฝังยังยืนยันไม่ได้ทั้งหมด
- Chromium จำลองไม่แทนการทดสอบบน Safari iPhone และ Android ทุกยี่ห้อ
- โค้ดใหม่, migration สถิติ/ใบจบหลักสูตร และ expiresAt ใน API ยังไม่ได้ deploy ดังนั้นผลในเครื่องไม่ใช่การรับรองว่า production ใช้การปรับชุดนี้แล้ว
- การทดสอบเหล่านี้ไม่ใช่การรับรองว่าระบบไม่มีบั๊กทุกกรณี
